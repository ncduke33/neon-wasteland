# NEON WASTELAND: SIEGE PROTOCOL

Playable web build of the cyberpunk tower defense. Same data as the game database:
10 heroes, 150 abilities, 18 units, 12 buildings, 12 hostiles, 30 waves.

Files
- index.html — page shell
- style.js — stylesheet (injected)
- markup.js — page markup (injected into #nw)
- icons.js — icon name to source URL map
- data.js — heroes, abilities, units, buildings, hostiles, waves
- app.js — rendering, loadout, coin shop, base panel, wave track

Art: icons from game-icons.net (Lorc, Delapouite, DarkZaitzev and contributors),
CC BY 3.0, loaded from the game-icons/icons repository. SVG only, no generated art.

# NEON WASTELAND — Fun Rebuild Plan
Reference loop: Mindustry (GPL-3.0, open source). Build phase, then wave, then spend, repeat.
Secondary references: Warzone 2100 (RTS camera and unit weight), 0 A.D. (unit variety and readable silhouettes).

## The loop we are copying
1. BUILD PHASE (90 sec or until you press READY). Place and upgrade turrets on lane nodes, spend scrap and circuitry, see exactly what is coming.
2. WAVE PREVIEW. Enemy composition, count, and boss flag shown before you commit, so the build phase is a decision, not a guess.
3. WAVE. You watch it play, with the option to trigger one hero ability and one emergency summon. Damage numbers, hit flash, screen shake, slow motion on boss death.
4. PAYOUT. Kills drop scrap immediately, wave clear pays a bonus, then back to build phase.
5. FAIL FORWARD. Core damage is visible, run ends cleanly with a stat card, permanent upgrades carry over.

## Why the current build feels flat
- Resources have almost nothing to buy during a run, so the economy has no tension.
- Waves arrive on a timer with no preview, so placement is guesswork.
- No feedback layer: no damage numbers, no impact, no sound cues, no camera response.
- The HUD is flat panels with no hierarchy, so nothing reads as urgent.

## Systems to build
1. Build phase screen: lane node grid, turret shop, upgrade path, sell, wave preview, READY button.
2. Turret families: rapid, splash, beam, slow field, and one support that buffs neighbours.
3. Economy: scrap income per kill, wave clear bonus, interest on unspent, so saving is a strategy.
4. Enemy roles: swarm, tank, shielded, healer, sapper, boss. Each forces a different answer.
5. Hero layer: one active ability per wave, cooldown, three slots, wildcard.
6. Juice: damage numbers, muzzle flash, impact particles, shake, slow-mo boss kill, combo counter.
7. Run summary card with a real score, best wave, kills, and what unlocked.
8. Permanent progression: base shop levels that change the opening build, not just stats.

## GUI refresh
- Dark glass panels with neon edge light and real depth.
- One accent colour per meaning: cyan is money, magenta is threat, amber is action.
- Big numbers for wave, core HP, and scrap. Everything else recedes.
- Bottom bar becomes three large targets: BUILD, ABILITY, READY.
- Motion: panels slide, buttons press, banners slam in.

## Milestones
M1 playable build phase and wave preview on the live site.
M2 turret families and enemy roles with a real economy.
M3 juice pass and run summary.
M4 permanent progression and daily modifiers.
